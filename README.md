# 伊布马里奥 · 进化大冒险

一个像素风的横版平台跳跃小游戏（纯 HTML5 Canvas，单文件，无依赖）：伊布吃下不同的食物会进化成不同的伊布，用每种进化的专属能力闯过关卡。

## 怎么玩

- **电脑**：浏览器打开 `index.html` 即可。
- **手机**：用浏览器打开同一个页面（放到任意静态托管，例如 GitHub Pages），横屏游玩，左下角方向键、右下角跳跃键，支持双指同时操作。竖屏时会提示把手机横过来。

| 操作 | 按键 |
| --- | --- |
| 移动 | ← → 或 A D（手机：◀ ▶） |
| 跳跃 / 上浮 | 空格 / ↑ / W（手机：跳）按住跳得更高 |
| 重新开始 | R |

## 食物与进化

| 食物 | 进化形态 | 能力 | 用来通过 |
| --- | --- | --- | --- |
| 蓝莓 | 水伊布 | 在水里游泳（按住跳跃上浮） | 水池 |
| 柠檬 | 雷伊布 | 跑得飞快，电网无效 | 电网 |
| 辣椒 | 火伊布 | 碰到木箱就烧掉（火会蔓延） | 木箱墙 |
| 树叶 | 叶伊布 | 二段跳 | 高墙 |
| 冰淇淋 | 冰伊布 | 冻住水面，在冰上行走 | 深水区 |
| 太阳饼 | 太阳伊布 | 下落时按住跳跃滑翔 | 大峡谷 |
| 月饼 | 月亮伊布 | 穿过黑影墙 | 黑影墙 |
| 彩虹糖 | 仙子伊布 | 碰到怪物把它变成爱心 | 怪物群 |

其他规则：踩在怪物头上可以打倒它；每收集 20 个金币加一条命；路牌和食物都是存档点；掉下悬崖或在水里憋气太久会损失一条命并回到存档点。

## 闪光伊布

每次进化都有 1/8 的概率变成闪光版（`index.html` 里的 `SHINY_RATE` 可改）：配色不同、周身冒星星、+300 分，HUD 名字旁显示 ✨，右上角图鉴上会打一颗星，通关结算会统计闪光数量。闪光配色是用色相映射从普通版自动生成的（银白伊布、紫粉水伊布、黄绿雷伊布、金黄火伊布、薄荷绿太阳伊布、蓝环月亮伊布、青绿冰伊布、粉蓝互换的仙子伊布）。

## 画面与素材

- 内部分辨率 384×224（16 像素瓦片），最近邻放大，桌面端按整数倍缩放保证像素整齐。
- 角色图是用户提供的拼贴图切出来的像素 PNG（普通 + 闪光共 18 张，base64 内嵌在 `index.html` 里），切图与闪光配色脚本在 `tools/extract/`，`tools/embed_sprites.py` 负责写回游戏。拼贴图里的角色是任天堂 / Game Freak 的宝可梦形象，仅供个人娱乐使用。
- 没有 PNG 时会回退到 `tools/gen_sprites.py` 生成的原创像素图。
- **替换角色素材**：在 `index.html` 旁新建 `assets/` 目录，放入 `eevee.png`、`vaporeon.png` 等 9 张图，会优先于内置图被使用。要求：角色朝右、脚贴图片底边、透明背景；也可以把两帧走路动画横向拼成一张（宽度约为高度的两倍）。
