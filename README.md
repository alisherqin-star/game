# 伊布马里奥 · 进化大冒险

一个纯 HTML5 Canvas 的横版平台跳跃小游戏：伊布吃下不同的食物会进化成不同的伊布，用每种进化的专属能力闯过关卡。

## 怎么玩

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。手机上会显示触屏按钮。

| 操作 | 按键 |
| --- | --- |
| 移动 | ← → 或 A D |
| 跳跃 | 空格 / ↑ / W（按住跳得更高） |
| 重新开始 | R |

## 食物与进化

| 食物 | 进化形态 | 能力 | 用来通过 |
| --- | --- | --- | --- |
| 蓝莓 | 水伊布 | 在水里游泳（↑ 上浮） | 水池 |
| 柠檬 | 雷伊布 | 跑得飞快，电网无效 | 电网 |
| 辣椒 | 火伊布 | 碰到木箱就烧掉（火会蔓延） | 木箱墙 |
| 树叶 | 叶伊布 | 二段跳 | 高墙 |
| 冰淇淋 | 冰伊布 | 冻住水面，在冰上行走 | 深水区 |
| 太阳饼 | 太阳伊布 | 下落时按住跳跃滑翔 | 大峡谷 |
| 月饼 | 月亮伊布 | 穿过黑影墙 | 黑影墙 |
| 彩虹糖 | 仙子伊布 | 碰到怪物把它变成爱心 | 怪物群 |

其他规则：踩在怪物头上可以打倒它；每收集 20 个金币加一条命；路牌和食物都是存档点；掉下悬崖或在水里憋气太久会损失一条命并回到存档点。
