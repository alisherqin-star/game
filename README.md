# 伊布马里奥 · 进化大冒险

一个像素风的横版平台跳跃小游戏（纯 HTML5 Canvas，单文件，无依赖）：伊布按原作的方式进化（进化石、苔藓岩 / 冰岩、白天 / 夜晚的羁绊、暖心支线），用每种进化的专属能力闯过关卡。

## 怎么玩

- **电脑**：浏览器打开 `index.html` 即可。
- **手机**：用浏览器打开同一个页面（放到任意静态托管，例如 GitHub Pages），横屏游玩，左下角方向键、右下角跳跃键，右上角"形态"切换形态、"地图"开地图。竖屏时会提示把手机横过来。

| 操作 | 按键 |
| --- | --- |
| 移动 | ← → 或 A D |
| 跳跃 / 上浮 | 空格 / ↑ / W（按住跳得更高） |
| 技能 | X / J / K（手机：跳跃键左边的"技"） |
| 切换形态 | 1～9、Tab 轮换，或点击左上角物品栏（1 伊布、2 水、3 雷、4 火、5 叶、6 冰、7 太阳、8 月亮、9 仙子） |
| 背包 | Esc / I / E |
| 地图 | M（方向键移动、+ - 或滚轮缩放） |
| 新游戏 | 标题菜单选"新游戏" |

## 界面

泰拉瑞亚风格：左上角是形态物品栏（选中格放大加金边，上方显示名字，鼠标悬停有说明，点击可切换），下面是技能图标和冷却；右上角是红心生命值、带金边的小地图、心之碎片和金币；左下角是消息记录；NPC 对话在屏幕中间的蓝色对话框；Boss 血条在底部。Esc 打开背包（形态、进化条件和进度、心之碎片、闪光、金币和角色信息），M 打开按瓦片绘制的全屏地图，未去过的地方是黑的。

## 银河恶魔城版（当前）

游戏正在从线性关卡改造成互通大地图，设计见 `DESIGN.md`。目前可玩的内容：起点村、草原（含大史莱姆 Boss、水之石）、湖泊（含湖蚌 Boss、雷之石）、雷电塔门口，共 14 个房间。

- 5 格血，心之碎片每 4 片加 1 格；碰到存档石回满血并记录位置，死亡回到最近的存档石并掉一半金币。
- 进化条件尽量贴近原作：水 / 雷 / 火伊布碰到对应的进化石；叶 / 冰伊布用伊布的样子靠近藏起来的苔藓岩 / 冰岩；太阳 / 月亮伊布用伊布的样子在白天 / 夜晚区域打倒 10 只怪物；仙子伊布要完成支线「迷路的小史莱姆」（打败大史莱姆后它会变成找孩子的史莱姆妈妈）。进化的总是伊布，碰到进化石时会先变回伊布。规则和位置见 `DESIGN.md` 第 3.1、3.2 节。
- 进化过的形态永久解锁，之后随时切换。能力门：水池要水伊布、电网要雷伊布、木箱要火伊布、裂墙要雷伊布高速撞、黑影墙要月亮伊布、锁门要集齐 8 种进化。
- 每种形态有一个主动技能（X）：伊布撞击、水伊布水枪（能打死刺河豚）、雷伊布电击（范围眩晕）、火伊布火花（烧木箱）、叶伊布飞叶快刀（回旋）、冰伊布冰冻光束（冻成可踩的冰块）、太阳伊布念力（穿墙）、月亮伊布暗影球（穿黑影墙）、仙子伊布魅惑之声（前方扇形魅惑）。Boss 吃技能伤害，湖蚌只在张开时。
- 进度自动存在浏览器本地（存档石处），标题画面可以继续。
- 关卡在 `tools/build_world.py` 里用字符画一间一间写，运行它会重新生成 `levels/world.json` 并嵌入 `index.html`；字符含义见文件头部注释。

## 闪光伊布

每次进化都有 1/15 的概率变成闪光版（`index.html` 里的 `SHINY_RATE` 可改）：配色不同、仿正作的闪光叮铃音效（WebAudio 合成，非官方音频）、白闪 + 一圈星星炸开 + 螺旋星星特效、周身冒星星、+300 分，HUD 名字旁显示 ✨，右上角图鉴上会打一颗星，通关结算会统计闪光数量。闪光配色是用色相映射从普通版自动生成的（银白伊布、紫粉水伊布、黄绿雷伊布、金黄火伊布、薄荷绿太阳伊布、蓝环月亮伊布、青绿冰伊布、粉蓝互换的仙子伊布）。

## 画面与素材

- 内部分辨率 384×224（16 像素瓦片），最近邻放大，桌面端按整数倍缩放保证像素整齐。
- 所有美术都是 `sprites/` 目录里的 PNG（原始像素尺寸、透明背景），游戏加载时从 `index.html` 内嵌的 base64 读取。改图流程：
  1. 用任意像素编辑器（Aseprite、Piskel 等）修改 `sprites/` 下的 PNG，或改 `tools/make_assets.py` 里的字符画后运行它重新生成
  2. 进化石、巨石、缎带和小史莱姆在 `tools/make_evolution_assets.py` 里，改完运行它重新生成
  3. 运行 `python3 tools/embed_assets.py` 写回 `index.html`
- 目录说明：`characters/` 9 只伊布（普通 + 闪光，朝右、脚贴底），`tiles/` 地形（草地、泥土、砖块、木箱、水面两帧、水体、冰面、电网两帧、黑影墙两帧、尖刺、单向平台），`items/` 三颗进化石、太阳 / 月亮标记、缎带和旧的 8 种食物图（暂未使用），`props/` 苔藓岩和冰岩，`npcs/` 迷路的小史莱姆，`enemies/` 史莱姆和蝙蝠各两帧，`ui/` 金币四帧、爱心、路牌、终点旗，`deco/` 云、灌木、树、小花。
- 角色图来自用户提供的拼贴图，由 `tools/extract/extract_sheet.py` 切出、`tools/extract/clean_sprites.py` 清理杂点并补描边，闪光版按色相映射生成。拼贴图里的角色是任天堂 / Game Freak 的宝可梦形象，仅供个人娱乐使用。

## 场景美术

`sprites/backgrounds`、`sprites/tiles` 和 `sprites/deco` 里新增了一套场景素材包，分森林、湖泊、洞穴、塔四套，说明见 `art/CLAUDE_HANDOFF.md`，素材审阅页是 `art/index.html`。

- 目前起点村和草原已经换成森林套：雾色天空加三层横向循环的视差背景，草地和泥土各四种变体按坐标选，房屋、树、长椅、栅栏等手摆装饰，地面小草按坐标自动撒。效果见 `docs/forest-ingame.png`。
- 区域用哪套由 `index.html` 里 `REGION` 的 `biome` 字段决定，套组本身定义在 `BIOME`。湖泊、湖底洞穴、雷电塔还是旧画面。
- 只换画面，不改碰撞和玩法。尖刺、电网、木箱、水、单向平台等仍用原来的瓦片，方便辨认。
- 装饰写在 `tools/build_world.py` 每个房间的 `deco=[(素材名, 列, 地面行[, 像素偏移]), ...]` 里，改完运行它重新生成世界；换了图片要再运行 `python3 tools/embed_assets.py`。
