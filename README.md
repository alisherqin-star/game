# 伊布马里奥 · 进化大冒险

一个像素风的横版平台跳跃小游戏（纯 HTML5 Canvas，单文件，无依赖）：伊布吃下不同的食物会进化成不同的伊布，用每种进化的专属能力闯过关卡。

## 怎么玩

- **电脑**：浏览器打开 `index.html` 即可。
- **手机**：用浏览器打开同一个页面（放到任意静态托管，例如 GitHub Pages），横屏游玩，左下角方向键、右下角跳跃键，右上角"形态"切换形态、"地图"开地图。竖屏时会提示把手机横过来。

| 操作 | 按键 |
| --- | --- |
| 移动 | ← → 或 A D |
| 跳跃 / 上浮 | 空格 / ↑ / W（按住跳得更高） |
| 技能 | X / J / K（手机：跳跃键左边的"技"） |
| 切换形态 | 1～9（按解锁顺序：1 伊布、2 水、3 雷、4 火、5 叶、6 冰、7 太阳、8 月亮、9 仙子）或 Tab 轮换 |
| 地图 | M |
| 新游戏 | 标题画面按 N（会覆盖存档） |

## 银河恶魔城版（当前）

游戏正在从线性关卡改造成互通大地图，设计见 `DESIGN.md`。目前可玩的内容：起点村、草原（含大史莱姆 Boss、蓝莓）、湖泊（含湖蚌 Boss、柠檬）、雷电塔门口，共 14 个房间。

- 5 格血，心之碎片每 4 片加 1 格；碰到存档石回满血并记录位置，死亡回到最近的存档石并掉一半金币。
- 吃过的食物永久解锁对应形态，之后随时切换。能力门：水池要水伊布、电网要雷伊布、木箱要火伊布、裂墙要雷伊布高速撞、黑影墙要月亮伊布、锁门要集齐 8 种进化。
- 每种形态有一个主动技能（X）：伊布撞击、水伊布水枪（能打死刺河豚）、雷伊布电击（范围眩晕）、火伊布火花（烧木箱）、叶伊布飞叶快刀（回旋）、冰伊布冰冻光束（冻成可踩的冰块）、太阳伊布念力（穿墙）、月亮伊布暗影球（穿黑影墙）、仙子伊布魅惑之声（前方扇形魅惑）。Boss 吃技能伤害，湖蚌只在张开时。
- 进度自动存在浏览器本地（存档石处），标题画面可以继续。
- 关卡在 `tools/build_world.py` 里用字符画一间一间写，运行它会重新生成 `levels/world.json` 并嵌入 `index.html`；字符含义见文件头部注释。

## 闪光伊布

每次进化都有 1/15 的概率变成闪光版（`index.html` 里的 `SHINY_RATE` 可改）：配色不同、仿正作的闪光叮铃音效（WebAudio 合成，非官方音频）、白闪 + 一圈星星炸开 + 螺旋星星特效、周身冒星星、+300 分，HUD 名字旁显示 ✨，右上角图鉴上会打一颗星，通关结算会统计闪光数量。闪光配色是用色相映射从普通版自动生成的（银白伊布、紫粉水伊布、黄绿雷伊布、金黄火伊布、薄荷绿太阳伊布、蓝环月亮伊布、青绿冰伊布、粉蓝互换的仙子伊布）。

## 画面与素材

- 内部分辨率 384×224（16 像素瓦片），最近邻放大，桌面端按整数倍缩放保证像素整齐。
- 所有美术都是 `sprites/` 目录里的 PNG（原始像素尺寸、透明背景），游戏加载时从 `index.html` 内嵌的 base64 读取。改图流程：
  1. 用任意像素编辑器（Aseprite、Piskel 等）修改 `sprites/` 下的 PNG，或改 `tools/make_assets.py` 里的字符画后运行它重新生成
  2. 运行 `python3 tools/embed_assets.py` 写回 `index.html`
- 目录说明：`characters/` 9 只伊布（普通 + 闪光，朝右、脚贴底），`tiles/` 地形（草地、泥土、砖块、木箱、水面两帧、水体、冰面、电网两帧、黑影墙两帧、尖刺、单向平台），`items/` 8 种食物，`enemies/` 史莱姆和蝙蝠各两帧，`ui/` 金币四帧、爱心、路牌、终点旗，`deco/` 云、灌木、树、小花。
- 角色图来自用户提供的拼贴图，由 `tools/extract/extract_sheet.py` 切出、`tools/extract/clean_sprites.py` 清理杂点并补描边，闪光版按色相映射生成。拼贴图里的角色是任天堂 / Game Freak 的宝可梦形象，仅供个人娱乐使用。
