# NPC 辨识加强方案 B

本方案 B 已确认采用，现已接入游戏和主素材图鉴。此目录中的对比图保留为确认时的历史记录。

上一版的配饰较小，且饱和度与伊布毛色接近。此版保留贴合身体的角度，通过更集中的色块和不同标志物增加识别距离。

| 职业 | 主配色 | 标志物 |
|---|---|---|
|村长|苔绿|叶帽＋圆眼镜|
|向导|湖蓝|斜蝴蝶结＋金铃铛|
|商人|莓红|宽围巾＋皮挎包|
|医师|奶白青绿|白头巾＋绿叶刺绣|
|探险家|橘红|护目镜＋橘色背包|
|园丁|嫩绿|小草帽＋绿围裙|
|矿工|蜂蜜黄|黄矿帽＋亮头灯|
|糕点师|奶油粉|蓬松厨帽＋粉领结|
|学者|葡萄紫|紫围巾＋随身书本|
|守卫|靛蓝|蓝头带＋小盾徽|

现有角色仍为村长、向导、商人；其他 7 款为备用职业。

预览图：`docs/npc-identity-proposal.png`；前三位放大对比：`docs/npc-identity-proposal-main.png`。

方案保留原图眼睛、鼻子与耳尖，仍使用 32×28 图片和 (16,28) 脚底锚点。PNG 保存在本文件夹，重建脚本为 `tools/preview_npc_identity.py`。
