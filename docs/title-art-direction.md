# 标题与封面美术

名称：伊布冒险物语：橡树的约定 / Eevee’s Adventure: Oakbound。

参考 [Owlboy 官方页面](https://www.owlboygame.com/) 的字标识别性与前后景层次，以及 [Eastward 官方美术](https://eastwardgame.com/media/) 的像素场景组织方法。没有导入或复制参考作品的素材。

## 当前画面规则

- 画布为 384×224 原生像素，所有线条与边缘保持硬像素。
- 三位角色采用原始透明素材，裁去留白后精确放大两倍，保留原始色板；撤销 1.5 倍缩放、描边淡化和混色。角色随独立场景构图重新安排；切换经短暂暮色过渡，避免两组角色相互叠加。
- 古树由后树冠、木质结构、前树冠三层组成。下部树干与板根统一绘制，根端由泥土和草叶部分遮挡；清除与树根穿插的石阶。
- 树的体量、上收的主枝、成片树冠、风化树皮与旧疤表现年代感；少量苔藓与橡叶刻印保留神秘感。结局花层单独保存，首页不展示。
- 房屋采用用户选择的圆润原有造型。
- A 为晨光村口启程，近景古树、村屋与道路；B 为湖畔夜宴，前景独立草坪、宽阔湖面与远处完整古树。野餐用品仅在 B 的草坪上，草坪没有道路。
- 石桥斜跨两岸，包含桥面、桥侧、拱口及石缝；围栏有独立板条、双横梁、柱帽、接头及脚边草。
- 标题提供中、日、英三种透明像素 PNG。英文主字母为逐字像素绘制，中日文字为粗字面。

## 构建与预览

依次运行 `tools/make_title_logo.py`、`tools/make_title_covers.py`、`tools/embed_assets.py`。

`docs/title-screen-polished.png` 是昼夜全景，`docs/title-details-review.png` 是四倍整数放大的细节图，`docs/title-character-fade-check.png` 检查昼夜渐变中间帧。

三语字标统一为系列名、主标题、橡果印记三层，撤下零散橡叶装饰。英文重画为较高的像素字母；中文与日文分别使用对应语言粗字形，透明图片为 240×104。

## 村口与湖景细化

A 的主路使用连续收窄的曲线接到屋门，村长站在根系外侧的平地；增加原有商贩与园丁 NPC、晾晒线、菜箱和浇水用品。B 的岛上古树按几何坐标加宽 35%、加高 25%，直接绘成原生像素，补足树皮、主枝和叶层，并增加岸边植物与水面细节。

## 标题画面的收尾（2026-10-22）

- 字标按设备像素的整数倍画（`drawTitleWordmark`）：窗口小时 120 宽、大时 180 宽，以 (288, 56) 为中心，边缘不再有不均匀的像素。
- A / B / 暂停按钮默认不显示，网址加 `?covers` 才出现；玩家看到的只有自动的昼夜轮换，黄昏过渡放慢到 1.8 秒。
- 菜单收窄到 104 宽、靠右，底下垫一层 42% 的深色底板；在 A 里只压到远处的房子和石桥，在 B 里只压到湖面。
- 人物放大两倍后的近黑描边换成画面自己的深色（白天 `#2e1f1a`，夜晚 `#1f2a33`，`warm_outline`），不再像贴上去的。
- 商人和园丁连同菜箱从菜单底下挪到小路旁（x 198 / 232），不再被按钮压住。
