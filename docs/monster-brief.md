# 怪物美术简报（给 Codex）

设计上的依据在 `DESIGN.md` 第 9 节（`claude/fun-pass` 分支）。这份只讲画什么、画多大、叫什么文件名。先做第一批，第二批等地下水道和火山洞的关卡做出来再画。

## 规格（和现有素材一致）

- 像素风，16px 地形网格；小怪 14～16 px 宽、8～16 px 高，精英不用单独画（代码放大 1.5 倍并蒙一层金色）。
- RGBA 透明 PNG，不抗锯齿；**默认朝左**（往右走时代码镜像）。
- 文件放 `sprites/enemies/`，命名 `<名字>_<帧>.png`，帧从 0 起；两帧够了（走路 / 扇翅），特殊状态单独一张。
- 画完跑 `python3 tools/build_art_catalog.py` 更新 `art/manifest.json`，再 `python3 tools/embed_assets.py` 内嵌；锚点用底边中心 `[width/2, height]`。
- 风格参考现有的 `slime_0.png`、`frog_0.png`：大眼睛、圆轮廓、两三种主色加一层暗色描边；要和伊布（24×20 左右）站在一起不抢戏。
- 受伤闪烁、头上的血点、发火的红「!」都是代码画的，不用画进图里。
